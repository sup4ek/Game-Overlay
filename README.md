# Game Overlay

Оверлей для Windows на Electron: клавиатура, клавиатура с мышью,
DualSense и Xbox. Поддерживает скины, изменение размеров в реальном
времени, сохранение настроек и управление из трея.

## Запуск

Нужны Node.js и Windows. В терминале из корня репозитория:

```powershell
cd "Game Overlay"
npm.cmd ci
npm.cmd start
```

## Проверки и сборка

Из каталога `Game Overlay`:

```powershell
npm.cmd test
npm.cmd run dist
```

Portable EXE появится в `Game Overlay/dist/Keyboard Overlay.exe`.
Зависимости, сборки и результаты тестов не включены в репозиторий.

## Управление

- Меню открывается при запуске; Ctrl+Alt+M открывает или закрывает его.
- Клик по значку в трее открывает настройки.
- «Перетащить» включает перемещение, Enter закрепляет оверлей.
- Ширина и высота применяются при вводе допустимого числа.
- Значок обновления рядом с крестиком переподключает выбранное устройство.

Геймпады используют Gamepad Viewer и требуют интернет.
Подробности и источники оформления — в [README приложения](Game%20Overlay/README.md).
