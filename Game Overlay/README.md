Keyboard Overlay — меню и скины

Иконка приложения и трея подготовлена из Иконка/Capa.jpg и включена
в assets/app.ico (размеры 16–256 px). Клик по значку в трее открывает
настройки; правый клик показывает «Настройки» и «Выход».

Обновление 14.09.2026: повторный запуск открывает настройки уже работающего
экземпляра. Меню также автоматически открывается при первом запуске.
Переподключение — компактная кнопка со значком обновления в шапке рядом
с закрытием. Для клавиатуры она перезапускает обработку клавиатуры и мыши
и сбрасывает подсветку удерживаемых кнопок; для геймпада повторяет загрузку.
Последний форм-фактор клавиатуры и геймпада сохраняется отдельно.
В настройках геймпада появился отдельный статус страницы и «Переподключить»:
кнопка повторяет загрузку после сетевой ошибки или падения страницы.
Статус страницы не означает, что физический контроллер уже подключён.
Проверки: npm test (в PowerShell при запрете сценариев — npm.cmd test).
Актуальная папка исходников: Game Overlay/Game Overlay.

Статус на 11.09.2026: в общее меню подключены готовые DualSense и Xbox.
Сначала выбирается устройство (Клавиатура / Геймпад), затем его форм-фактор.
Клавиатура: Keyboard или Keyboard + Mouse. Геймпад: DualSense или Xbox.
В меню доступны 15 скинов DualSense и 14 Xbox по фотографиям из «Макеты джойстика».
Названия DualSense взяты с фотографий, Xbox — из имён файлов.
Цвета, градиенты и узоры адаптированы к существующим анимированным оверлеям;
фотографии не подставляются вместо интерактивных устройств.
Реестр скинов: gamepad-skins.js; оформление корпуса: gamepad-theme.js.
Контуры панелей DualSense огибают тачпад и оставляют правые кнопки целиком
на внешней панели; координаты четырёх кнопок закреплены относительно корпуса.
В Xbox отключена рекламная анимация автора и исключён её слой из фона.
Верхняя граница окраски Xbox проходит по шву корпуса под LB/RB: бамперы
сохраняют исходный цвет и подсветку нажатия во всех скинах.
Выбор скина каждого геймпада хранится отдельно в window-state.json.
Смена скина не перезагружает страницу и сохраняет текущие состояния ввода.
Форм-фактор Xbox взят из сохранённой страницы в «Формфактор XBOX»:
https://gamepadviewer.com/?p=1&css=https%3A%2F%2Fjayraydee.me%2FAssets%2FFreeport%2FXSX-Black%2FXSX.css
Размер Xbox по умолчанию 320×283, также сохраняется отдельно.
Ширина и высота геймпадов независимо масштабируют весь рисунок по соответствующей
оси; кнопки, стики, подсветка и скин масштабируются вместе с корпусом.
При независимом изменении сторон меняются пропорции геймпада.
gamepad-size.js управляет масштабированием, страничный zoom всегда равен 1.
По краям оставлен небольшой отступ; рисунок не обрезается при уменьшении окна.

DualSense использует исходный URL и тёмный скин из Overlay/config.js;
копия конфигурации включена в приложение как dualsense-config.js.
Отдельно запускать старый Overlay не требуется. Для DualSense нужен интернет.
Подключите контроллер и нажмите кнопку для его обнаружения Gamepad Viewer.
Страница геймпада работает в отдельном BrowserView без доступа к IPC приложения.
При возврате к клавиатуре страница закрывается, выбранный скин клавиатуры сохраняется.
Размер DualSense по умолчанию 283×283; его размер сохраняется отдельно от клавиатуры.
Для него работают те же «Перетащить», Enter, размер и «Выход».
Исходный тёмный DualSense доступен как Black Midnight, Xbox — как Carbon Black.
При ошибке загрузки меню остаётся доступным: восстановите интернет и переключитесь
с клавиатуры обратно на геймпад, чтобы повторить загрузку.

Ctrl+Alt+M — открыть / закрыть отдельное окно настроек.
Оно появляется по центру рабочей области монитора, на котором находится курсор.
Окно можно перемещать за шапку; при следующем открытии оно снова центрируется.
Закрыть меню также можно крестиком в шапке или Escape.

В меню работают скины, форм-фактор, ширина/высота, «Перетащить» и «Выход».
Форм-факторы: Keyboard (клавиатура) и Keyboard + Mouse (клавиатура и мышь справа).
Из макета перенесена только мышь, без дополнительных клавиш WASD.
Первый размер Keyboard + Mouse — 600×351; размеры обоих вариантов запоминаются отдельно.
Скины: Оригинальный, Spring, Summer,
Autumn, Winter, Custom.
Оригинальный — полностью чёрные устройства без цветного свечения, с серыми обозначениями.
Summer — прежний цветной Оригинальный (синий, розовый и янтарный).
Старый вариант Summer заменён этим оформлением. Остальные палитры — из skins/babel.txt.
Скин применяется одновременно к клавиатуре и мыши.
Обрезанная клавиатура (27 клавиш), пропорции клавиш и исходная анимация
нажатий сохранены. Цвета распределены стабильно: возвращение к скину
не перемешивает их. Custom — готовая палитра, не редактор цветов.

Выбранный скин сохраняется в localStorage профиля Electron и применяется
при следующем запуске. При неизвестном скине включается оригинальный.
При обновлении сохранённый старый Оригинальный автоматически становится Summer.
Новый Оригинальный выбирается в меню; при чистом запуске он используется по умолчанию.
Размер, положение, форм-фактор и размеры каждого варианта сохраняются в window-state.json в каталоге userData Electron.
После отключения монитора или изменения разрешения окно возвращается в видимую область.

Ширина/высота обновляются автоматически при вводе допустимого целого числа.
Пустые и промежуточные недопустимые значения не меняют размер оверлея.
Минимум — 200×180 для Keyboard и 320×180 для Keyboard + Mouse;
максимум ограничен рабочей областью монитора оверлея.
«Перетащить»: меню скрывается, клавиатуру можно переместить мышью.
Enter завершает перемещение, сохраняет положение и возвращает меню.
Во время перемещения Ctrl+Alt+M не действует; вне перемещения Enter не меняет режим.
«Выход» завершает оба окна и останавливает системный hook.
Ctrl+Alt+L и Ctrl+Alt+Q полностью удалены. Обычный режим всегда пропускает клики.
Настройки принимают ввод в собственном окне. Позиция, размер и режим пропуска
кликов клавиатуры при открытии меню не меняются. Скин обновляется сразу через IPC.
Закрытие настроек не завершает оверлей.

Мышь показывает нажатия ЛКМ, ПКМ, средней кнопки, Mouse4 и Mouse5.
Передняя (верхняя) боковая кнопка — Mouse5, задняя (нижняя) — Mouse4. Вращение колеса и движение курсора не отображаются.
Нажатия поступают из системного hook даже без фокуса окна. Ввод не блокируется.
При смене скина или форм-фактора удерживаемые кнопки сохраняют состояние;
при перезапуске hook подсветка клавиш и кнопок мыши сбрасывается.

Запуск: npm start
Portable-сборка Windows x64: npm run dist
Результат: dist/Keyboard Overlay.exe

skins.js содержит реестр палитр. renderer.js применяет их к общей разметке;
style.css сохраняет общий внешний вид и анимацию; settings.html, settings.js
и settings.css отвечают за отдельное окно меню.
Перехват клавиатуры и IPC не дублируются между скинами.
layouts.js описывает форм-факторы; mouse.css оформляет общий SVG мыши.
keyboard-hook.ps1 содержит оба Windows hooks в одном вспомогательном процессе.
